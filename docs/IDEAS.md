# Ideas backlog (not built yet)

A running list of ideas. Nothing here is in the game until it's picked and built.

## Two currencies

- **Bits (free).** Earned in play:
  - first clear of a level
  - each new star
  - a daily seed challenge
  - streaks

  Spent on cosmetics and on hints (a hint costs Bits, it never gives the full answer).
- **Cores (paid, later).** Cosmetic-only premium currency: skins, themes, decor bundles.
  - Rule: never pay-to-win, never buy solutions or skip levels.
  - Everything bought with Cores should also have a slower Bits path, or be clearly a bonus-only bundle.

## Cosmetics

- **Drone skins:**
  - crop-duster yellow
  - stealth black
  - retro 8-bit
  - neon outline
  - wooden toy
  - each campaign's mascot machine in Python colors
- **Drone extras:**
  - LED colors
  - propeller trail/sparkle
  - hover style (smooth vs bouncy)
- **Editor themes:**
  - green CRT terminal with scanlines
  - Monokai-style
  - Solarized
  - high-contrast
  - paper/light
- **Editor fonts and cursor styles.**
- **Farm decor:**
  - fence styles: white picket, stone wall, laser fence
  - scarecrow, barn, mailbox, windmill
  - seasonal biomes: autumn, snow
- **Effects:**
  - harvest effects (confetti, pixel burst, coin pop)
  - victory animations
- **Profile:**
  - operator titles earned from feats ("Off-by-One Survivor", "Loop Lord", "Zero-Waste Farmer")
  - badges

## Ways to earn Bits

- **Daily seed:** everyone gets the same map that day, with a leaderboard by ticks and by lines of code.
- **Efficiency bonuses:** fewest lines, no wasted ticks (no bumps, no lost crops).
- **Replays:** replaying a level on a new random seed with your existing code ("does your code generalize?").
